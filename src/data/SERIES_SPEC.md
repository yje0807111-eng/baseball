# 시리즈 데이터 규격 (KBO 증강 드래프트)

게임에서 드래프트 라운드마다 무작위 **시리즈**(구단의 한 시즌, 국가대표 대회, 레전드 모음) 하나가 나오고,
플레이어는 그 시리즈의 선수 중 한 명을 900 CP 샐러리 캡 안에서 영입한다.
영입가(CP)는 능력치로 계산하는 종합 능력치(overall)에서 나온다. **overall은 넣지 않는다** — 엔진이 계산한다.

## 파일

- 시리즈 하나당 JSON 파일 하나: `C:\Users\Home\Desktop\baseball\src\data\series\<id>.json` (UTF-8, 들여쓰기 2칸)
- 작성 후 반드시 검증: `node C:\Users\Home\Desktop\baseball\scripts\validate-series.mjs <파일경로...>` → `OK`가 나와야 한다.
  인자 없이 돌리면 시리즈 사이도 검사한다: 같은 구단·같은 해 시리즈 중복 금지, **같은 선수의 같은 시즌은 어느 시리즈에서든 포지션·투타·능력치가 같아야 한다.**
- 형식: 선수 한 명당 한 줄. 시리즈를 추가·삭제하면 `node scripts/series-catalog.mjs`로 구단별·연도별 목록(`SERIES_CATALOG.md`)을 다시 만든다.

## 시리즈 필드

| 필드 | 타입 | 규칙 |
|---|---|---|
| `id` | string | 소문자-케밥. 예: `2017-kia`, `2008-beijing`, `legend-foreign` |
| `kind` | `"team"` \| `"national"` \| `"legend"` | 구단 시즌 / 국가대표 대회 / 레전드 모음 |
| `year` | number \| null | team·national은 그 해. legend는 `null` (선수별 `year`가 따로 있음) |
| `title` | string | **그 해 당시** 이름. 예: `"해태 타이거즈"`, `"SK 와이번스"`, `"넥센 히어로즈"`, `"베이징 올림픽 국가대표"`, `"외국인 레전드"` |
| `franchise` | string \| null | team은 필수: `KIA`(해태 포함) `SAMSUNG` `LG`(MBC 포함) `DOOSAN`(OB 포함) `SSG`(SK 포함) `LOTTE` `HANWHA`(빙그레 포함) `KIWOOM`(넥센·히어로즈 포함) `NC` `KT` `HYUNDAI`(태평양 돌핀스 포함) `SSANGBANGWOOL`. 구단별 legend는 그 구단 코드, 외국인 레전드 등 구단 없는 legend와 national은 `null` |
| `champion` | `true` (선택) | 한국시리즈 우승 구단 시즌만 넣는다. 아니면 필드를 뺀다. 게임의 "가을의 왕조" 모드가 이 필드로 팀을 고른다 |
| `subtitle` | string | 30자 이하, 검증된 성과. 예: `"한국시리즈 우승 · 정규시즌 1위"`, `"9전 전승 금메달"` |
| `blurb` | string | 90자 이하, 야구를 잘 모르는 사람에게 이 팀/대회가 왜 유명한지 1~2문장 |
| `players` | array | 10~18명 (드래프트 선반이 한 줄 18칸. 18명보다 많은 시리즈는 게임이 포지션마다 1명씩 넣고 섞어 18명을 뽑는다) |
| `notes` | string[] | 검증 못 한 부분, 추정한 수치. 없으면 `[]` |

### 포지션 구성 (시리즈마다 최소)

선발 `SP` 3명 · 불펜/마무리 `RP` 2명 · `C` 1명 · `1B` `2B` `3B` `SS` 각 1명 · 외야 `OF` 2명.
나머지는 자유 (`DH` 포함). 실제로 그 포지션을 주로 맡은 선수여야 한다.

## 선수 필드

| 필드 | 타입 | 규칙 |
|---|---|---|
| `personId` | string | 동일 인물 판별 키. 기본은 이름 그대로. **동명이인**이면 구분자: `"박찬호(투수)"`, `"박찬호(유격수)"`, `"이병규(1974)"`처럼 출생연도나 역할 |
| `name` | string | 한글 이름. 외국인은 KBO 등록명 (예: `"테임즈"`, `"니퍼트"`) |
| `year` | number | 능력치가 나타내는 시즌 |
| `team` | string | 그 시즌 소속 약칭: `KIA` `해태` `삼성` `LG` `MBC` `두산` `OB` `SK` `SSG` `롯데` `한화` `빙그레` `현대` `넥센` `키움` `NC` `KT`, 해외면 `"요미우리"` `"한신"` `"MLB 텍사스"` 등 |
| `position` | `SP` `RP` `C` `1B` `2B` `3B` `SS` `OF` `DH` | 그 시즌 주 포지션 |
| `hand` | `"L"` \| `"R"` \| `"S"` | 타자는 타석(S=스위치), 투수는 던지는 손 |
| `isForeign` | boolean | 외국인 선수 여부 |
| `stats` | object | 타자: `power` `contact` `speed` `defense` / 투수: `stuff` `control` `stamina` `stability`. 전부 40~99 정수 |
| `note` | string | 24자 이하, 검증된 사실 (예: `"38홈런·40도루 MVP"`). 없으면 `""` |
| `source` | string | 근거 기록 한 줄 + 출처. 예: `".347/.420 38HR 40SB — statiz"`, `"20승 ERA 3.44 193.1IP 158K 45BB — namu"` |

- **국가대표(national)** 시리즈: 능력치는 **그 해 소속팀 시즌 기록** 기준 (KBO / NPB / MLB). `team`은 그 소속팀.
- **레전드(legend)** 시리즈: 각 선수의 **커리어 최고 시즌 하나**를 골라 `year`에 넣는다.
  구단별 레전드는 id `legend-<구단 코드 소문자>` (예: `legend-kia`, `legend-doosan`), title `"해태·KIA 레전드"`처럼 옛 이름까지.
  그 구단 소속 시즌 기록만 쓴다 (`team`은 그 해 이름: 해태/KIA). 외국인 레전드는 `legend-foreign`, franchise `null`.
  역사가 짧아 18명을 못 채우는 구단(NC·KT)은 `legend-nc-kt` 한 시리즈로 합친다 (franchise `null`).
  테마 레전드는 franchise `null`, id는 `legend-1980s`·`legend-ace`·`legend-hr`·`legend-mvp`처럼 테마 이름.
  시대별(`legend-1980s` 등)은 그 연대 시즌만, 테마별은 테마에 맞는 시즌만 고르고 여러 구단에서 고르게 뽑는다.
  이미 다른 시리즈에 같은 선수·같은 시즌이 있으면 그 값을 그대로 쓴다.

## 능력치 기준 (50~110 · 그 시즌 리그 평균 = 78)

기록을 그대로 재지 않고 **그 시즌 리그 평균과 견준다**. 1982년은 K/9 이 4.1, 2024년은 8.1 이라
같은 탈삼진이라도 시대에 따라 값이 달라야 하기 때문이다. 리그 평균 표는 `data/kbo/league.json`
(`node scripts/league-norms.mjs data/kbo` 가 만든다), 변환은 `scripts/stat-to-rating.mjs` 가 한다.

타자 — 리그 평균 대비 배수
- `contact` ← 타율: 0.78배→62, 0.90배→70, **평균→78**, 1.08배→85, 1.16배→92, 1.25배→100, 1.40배→110
- `power` ← 홈런(550타석 환산): 0→52, 0.5배→69, **평균→80**, 1.4배→88, 2배→97, 2.8배→105, 3.6배→110
- `speed` ← 도루(550타석 환산): 0→55, 0.5배→72, **평균→81**, 1.8배→92, 2.8배→101, 4배→110
- `defense` ← 자리: 유격 90 · 포수 88 · 2루 85 · 외야 82 · 3루 79 · 1루 59 · 지명 55
  (골든글러브급 +16, 준수한 주전 +8, 허술하면 −11)

투수 — 탈삼진·이닝은 많을수록, 볼넷·평균자책은 적을수록
- `stuff` ← K/9 비율: 0.65배→62, 0.82배→70, **평균→78**, 1.18배→87, 1.35배→95, 1.6배→104, 1.9배→110
  (평균자책이 리그의 0.6배 미만이면 +5, 1.3배 초과면 −5)
- `control` ← BB/9 역비율: 0.65배→62, **평균→78**, 1.25배→88, 1.6배→98, 2.1배→106
- `stamina` ← 선발 이닝 비율: 0.45배→60, 0.7배→70, **평균→80**, 1.25배→90, 1.45배→98, 1.7배→106.
  불펜은 이닝과 무관하게 55~73
- `stability` ← 평균자책 역비율: 0.7배→62, 0.85배→70, **평균→78**, 1.2배→88, 1.45배→97, 1.8배→105
  (WHIP 1.05 미만 +4, 1.45 초과 −4)

어느 시대를 뽑아도 평균이 78 이라 유불리가 생기지 않는다. 투수와 타자도 같은 눈금 위에 있다.
MVP·트리플크라운 같은 전설적 시즌은 기준보다 +3~5까지 손으로 올려도 된다. 평범한 주전은 72~84.

## 검증 원칙

- WebSearch / WebFetch로 **로스터 소속과 시즌 기록을 직접 확인**한다 (namu.wiki, statiz.sporki.com, koreabaseball.com, 위키백과).
- 확인이 안 되는 선수는 **추측해서 넣지 말고 빼거나 확인된 다른 선수로 대체**한다.
- `note`와 `subtitle`, `blurb`에는 확인된 사실만 쓴다.
