# 감독·코치 데이터 규칙

내 라커(본 게임)의 코치진 네 자리 — 감독 · 수석코치 · 타격코치 · 수비·투수코치 — 에 선임할 후보.
데이터는 `src/data/staff/managers.json`(감독)과 `src/data/staff/coaches.json`(코치 셋)에 두고, `src/myteam/staff.js`가 읽는다.

## 항목

```json
{ "id": "mg-kimeungyong", "name": "김응용", "role": "manager", "era": "1983-2004", "cost": 68,
  "effect": { "bat": 2, "clutch": 1 }, "note": "한국시리즈 10회 우승", "source": "해태 1983~2000·삼성 2001~2004 감독, KS 우승 10회 — namu" }
```

| 필드 | 설명 |
|---|---|
| `id` | 감독 `mg-`, 수석 `hc-`, 타격 `bc-`, 수비·투수 `pc-` + 이름 로마자 소문자(붙여 씀). **이미 있는 id는 절대 바꾸지 않는다** (사용자 저장 데이터가 id로 기억함) |
| `name` | 한글 이름 |
| `role` | `manager` · `head` · `batting` · `pitching` |
| `era` | 그 역할로 KBO 1군에서 일한 대표 기간. 감독 `"1983-2004"`, 현직이면 `"2019-"`. 코치 `"2008-2015"` |
| `cost` | 아래 산정식으로 계산한 CP |
| `effect` | 아래 키만. 값이 0인 키는 넣지 않는다 |
| `note` | 24자 이하, 확인된 사실 (예: `"한국시리즈 10회 우승"`, `"SK 왕조 투수코치"`) |
| `source` | 근거 한 줄 + 출처 (구단·연도·역할·성과) |

## 효과 키와 점수

| 키 | 뜻 | 1점당 |
|---|---|---|
| `bat` | 타자 컨택·파워 + | 1 |
| `field` | 야수 수비 + | 1 |
| `pitch` | 투수 구위·제구 + | 1 |
| `stamina` | 투수 체력 + | 4 |
| `steal` | 도루 성공률 + | 0.02 |
| `clutch` | 승부처 지시 횟수 + | 1 = 1.5점 |

값은 정수(`steal`만 소수 둘째 자리). 한 키 최대: `bat`·`field`·`pitch` 3, `stamina` 12, `steal` 0.06, `clutch` 1.

## 점수 (effect 합)

감독
- 한국시리즈 우승 3회 이상: **4점**
- 우승 1~2회: **3.5점**
- 우승은 없지만 한국시리즈 진출·국가대표 감독 등 뚜렷한 성과: **3점**
- 효과 방향은 그 감독의 알려진 야구 색깔로 (예: 관리 야구 → `field`·`pitch`, 발야구 → `steal`, 승부사 → `clutch`)

코치
- 우승팀 해당 파트 코치를 여러 번 했거나, 리그 최고 수준 성과(팀 타율·팀 ERA 1위 등)가 확인되는 코치: **3점**
- 1군 해당 파트 코치 경력이 길고 성과가 확인되는 코치: **2.5점**
- 그 밖에 1군 코치 경력이 확인되는 코치: **2점**
- 효과는 역할에 맞게: 타격코치 → `bat`(+`steal`), 수비·투수코치 → 투수코치면 `pitch`·`stamina`, 수비코치면 `field`, 수석 → 두세 키에 나눠서

## CP

- 감독: `cost = 40 + 7 × 점수` (4점 68 · 3.5점 64.5→65 · 3점 61) — 반올림
- 코치: `cost = 16 + 6 × 점수` (3점 34 · 2.5점 31 · 2점 28)

## 조사 원칙

- WebSearch / WebFetch 로 **KBO 1군에서 그 역할을 맡은 구단·연도**를 직접 확인한다 (namu.wiki, 위키백과, 구단 발표 기사).
- 확인이 안 되는 사람은 넣지 않는다. 역할이 섞였던 사람은 가장 대표적인 역할 하나로.
- 같은 사람은 한 역할로 한 번만 (감독과 코치 모두 했다면 감독 목록에만 넣는다).
- 선수 시절이 유명한 사람을 우선하되, 코치로서 실제 경력이 확인되어야 한다.
